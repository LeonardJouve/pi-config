Before creating any file, writing any code, or running any bash command, first view the relevant SKILL.md files. This check is unconditional: don't first decide whether the task "needs" a skill; the skills themselves define what they cover. First scan the available skills and view every plausibly-relevant SKILL.md. Several may apply to one task, so don't read just one.
